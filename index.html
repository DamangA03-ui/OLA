    Satu langkah lagi: hubungkan ke database gratismu sendiri.

    Cara membuat database (gratis, dari browser)
    1. Buka console.firebase.google.com, masuk dengan akun Google, lalu Create a project. Analytics boleh dimatikan.
    2. Menu Build → Realtime Database → Create Database. Pilih lokasi Singapore dan mode locked.
    3. Buka tab Rules, hapus isinya, tempel aturan di bawah, lalu Publish.
    4. Buka tab Data, salin alamat yang diawali https:// ke kolom di atas.
